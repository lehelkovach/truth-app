# Live translator passages

Short, widely quoted primary-source passages from the AI-risk debate, used by
`npm run translate:live` to run the Anthropic provider against real prose.

**Wording is unverified.** These were transcribed from memory of the widely
quoted text because the session that wrote them had no web access. The
translator's mechanics do not depend on exact wording (alignment is checked
against the text fed in, not the original), but **verify against the original
before citing any of them.**

| File | Author, year | Source | Why it is here |
|---|---|---|---|
| `good-1965.prose.txt` | I. J. Good, 1965 | "Speculations Concerning the First Ultraintelligent Machine" | The canonical intelligence-explosion argument: a definition, a premise and a "therefore", with a conditional proviso. |
| `turing-1951.prose.txt` | Alan Turing, 1951 | "Intelligent Machinery, A Heretical Theory" | An extrapolation ("it seems probable… we should have to expect") — tests whether the translator marks modality and scheme honestly. |
| `cais-2023.prose.txt` | Center for AI Safety, 2023 | Statement on AI Risk | A single normative claim with no argument attached — tests that the translator does not invent one. |
