# Comparison with existing tools

Compiled 2026-10-27 from each tool's documentation or repository as read that day. Rule for cells: **no** only where documentation shows absence or the feature is clearly out of scope; otherwise **not documented**. Every cell carries a source key that resolves to a URL in the per-tool notes and the Sources list. Argit's own row is in the paper (§8); it is not graded here because it would be self-graded.


Columns: (a) formal argumentation semantics; (b) logical / first-order evaluation of claim content; (c) versioned history of the case; (d) semantic diff between versions; (e) branches or forks; (f) evaluation diff; (g) concept grounding / equivocation detection; (h) evidence or source provenance per claim; (i) fallacy or scheme annotation with critical questions; (j) non-aggregated outputs (no single score or winner); (k) open source and license; (l) automated tests shipped in the repo.

### Per-tool notes and source keys

**Argdown.** A Markdown-like text syntax for argument maps with support, attack, undercut, entail, contrary and contradictory edges; exports PDF, images and a web component; VS Code extension and CLI; v2.0 released December 2025. A1 https://argdown.org/ ; A2 https://argdown.org/guide/elements-of-an-argument-map.html ; A3 https://github.com/christianvoigt/argdown ; A4 https://github.com/christianvoigt/argdown/tree/master/packages/argdown-core

**OVA3.** Browser-based AIF argument analysis (Online Visualisation of Argument) from ARG-tech, Dundee; monological and dialogical analysis with IAT, PDF annotation, collaborative editing, saving to AIFdb. O1 https://github.com/arg-tech/OVA3 ; O2 https://ebooks.iospress.nl/doi/10.3233/978-1-61499-436-7-463 ; O3 https://ova.arg.tech/

**Rationale.** Van Gelder's argument-mapping product (grouping, reasoning and advanced-reasoning maps; manual evaluation). The site is run by Kritisch Denken BV, Amsterdam (trade names Kritisch Denken, ReasoningLab, Austhink). No page read mentions Kialo; I found no evidence that Kialo owns Rationale, so drop the "Kialo-owned" phrase unless a source turns up. R1 https://www.rationaleonline.com/ ; R2 https://www.rationaleonline.com/about ; R3 https://docs.rationaleonline.com/guide/evaluating ; R4 https://docs.rationaleonline.com/guide/basis-boxes ; R5 https://docs.rationaleonline.com/guide/table-of-contents

**AGORA-net.** Hoffmann's collaborative web argument-mapping tool (Georgia Tech), public since August 2012, more than 10,000 maps; AGPL source on GitHub with a Flash client. The live site did not resolve when checked. G1 https://urbanresearch.iac.gatech.edu/publications/pub/4264 ; G2 https://github.com/MichaelHoffmann/AGORA ; G3 https://participatedb.com/tools/agora-net

**Carneades 4.** Gordon's Go implementation: Dung solver (four semantics), CAES structured evaluator with proof standards, cyclic graphs, IBIS, scheme-based argument construction, AIF/LKIF/CAF/AGXML/YAML input; last release 4.3 (July 2017). C1 https://github.com/carneades/carneades-4 ; C2 https://carneades.github.io/ ; C3 https://raw.githubusercontent.com/carneades/carneades-4/master/README.md ; C4 https://github.com/carneades/carneades-4/tree/master/src/engine/caes

**Kialo.** Closed-source pro/con debate-tree platform (launched 2017) with impact votes, perspectives, sources view, edit suggestions, cloning. K1 https://www.kialo.com/tour ; K2 https://support.kialo.com/en/hc/about-voting/ ; K3 https://support.kialo.com/en/hc/understanding-perspectives/ ; K4 https://support.kialo.com/en/hc/viewing-sources-in-discussions/ ; K5 https://support.kialo.com/en/hc/cloning-a-discussion/ ; K6 https://support.kialo.com/en/hc/editing-a-claim/ ; K7 https://en.wikipedia.org/wiki/Kialo

**DebateGraph.** Cloud-based collaborative deliberation mapping (co-founded 2008 by Peter Baldwin and David Price) with multiple views, ratings, citations, cross-links and a History tab. D1 https://debategraph.org/debategraphabout ; D2 https://debategraph.org/Details.aspx?nid=65027 ; D3 https://en.wikipedia.org/wiki/Debategraph

**ArgueMapper + Arguebuf.** Client-only argument-graph editor and a Protobuf graph format (ReCAP, Trier) with import of AIF, OVA, SADFace, Argdown, BRAT and Kialo and export to Arguebuf and AIF. M1 https://github.com/recap-utr/arguemapper ; M2 https://github.com/recap-utr/arguebuf-python ; M3 https://raw.githubusercontent.com/recap-utr/arg-services/main/proto/arg_services/graph/v1/graph.proto ; M4 https://github.com/recap-utr/arguemapper/blob/main/.github/workflows/check.yml ; M5 https://ebooks.iospress.nl/doi/10.3233/FAIA220176

**PyArg.** Open-source Python package (`python-argumentation`) plus web app for abstract argumentation, ASPIC+ and ABA: semantics, explanations, generators, stability and relevance algorithms. P1 https://github.com/DaphneOdekerken/PyArg ; P2 https://github.com/DaphneOdekerken/PyArg/tree/main/src ; P3 https://ceur-ws.org/Vol-3546/paper14.pdf ; P4 https://daphneodekerken.github.io/PyArg/

**Monkeypuzzle.** Free GPL-3 web argument-analysis tool from Edinburgh Napier (Douglas and Wells, CMNA 2017) in the Araucaria/OVA tradition; repository last updated 2019. Z1 https://ceur-ws.org/Vol-2048/paper09.pdf ; Z2 https://github.com/ARG-ENU/monkeypuzzle_web ; Z3 https://github.com/ARG-ENU
